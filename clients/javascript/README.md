# rest-exchange-protocol-client (deprecated)

This package has been merged into [`rest-exchange-protocol`](https://www.npmjs.com/package/rest-exchange-protocol). Install that package instead and import from its `/client` subpath:

```ts
import { REPClient } from 'rest-exchange-protocol/client';
```

This package now only re-exports `rest-exchange-protocol/client` for backwards compatibility and will not receive further updates.
